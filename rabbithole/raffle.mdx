One raffle spans four weekly entry-allocation periods. Your entries from all four weeks are added together for the final draw, and each wallet can win only once in a raffle.

The raffle draw and the [$500 weekly tier reward pool](/rabbithole/tiers-and-leaderboard#the-weekly-reward-pool) are separate systems. Both use the same weekly tier, but they calculate rewards differently.

## How Entries Are Calculated

At the end of each week, Rabbithole determines your tier from the unweighted USD value of rewards you claimed during that week. See [Tiers and Leaderboard](/rabbithole/tiers-and-leaderboard#tiers) for the thresholds and timing.

Each eligible campaign has a campaign multiplier of `1×`, `2×`, or `5×`. This multiplier weights the claimed USD from that campaign before your tier multiplier is applied.

| Tier | Entry multiplier |
| --- | ---: |
| Bronze | `0×` |
| Silver | `1×` |
| Gold | `2×` |
| Platinum | `4×` |
| Diamond | `8×` |

```text
weighted claimed USD = Σ(claimed USD from campaign × campaign multiplier)

weekly entries = floor(weighted claimed USD × tier multiplier)
```

### Worked Example

Suppose you claim `$10.25` from a `1×` campaign and `$1.50` from a `5×` campaign during one week.

1. Your unweighted claimed value is `$11.75`, which puts you in Gold for that week.
2. Your weighted claimed value is `$10.25 × 1 + $1.50 × 5 = $17.75`.
3. Gold has a `2×` tier multiplier, so the result is `$17.75 × 2 = 35.5`.
4. The result is rounded down, giving you **35 entries** for the week.

The campaign multiplier changes the contribution from a particular campaign. The tier multiplier applies once to the total weighted value. Your four finalized weekly entry totals are combined when the raffle closes.

## The Public Snapshot

After the fourth week, the entry pool is frozen in a public snapshot:

```http
GET https://api-tbi.boost.xyz/raffles/{raffleId}/snapshot
```

The endpoint returns canonical JSON in this shape:

```json
{
  "version": 2,
  "raffleId": 3,
  "numberOfWinners": 3,
  "rows": [
    {
      "canonicalIndex": 0,
      "walletAddress": "0x1111111111111111111111111111111111111111",
      "ticketCount": "50"
    },
    {
      "canonicalIndex": 1,
      "walletAddress": "0x2222222222222222222222222222222222222222",
      "ticketCount": "75"
    }
  ],
  "totalTickets": "125"
}
```

`raffleId` identifies the draw, `numberOfWinners` fixes the number of draws, `rows` contains every eligible wallet and its entry count, and `totalTickets` is the sum of those counts. Entry counts are strings so large integers remain exact.

Wallet addresses are lowercase and sorted lexicographically. `canonicalIndex` is the wallet's zero-based position in that order. The order matters when reproducing the winners.

## The On-Chain Commitment

Rabbithole hashes the exact compact UTF-8 JSON with `keccak256` before requesting randomness. To reconstruct the committed object, preserve this property order:

1. `version`
2. `raffleId`
3. `numberOfWinners`
4. `rows`
5. `totalTickets`

Each row must use `canonicalIndex`, `walletAddress`, then `ticketCount`. Rows stay in ascending `canonicalIndex` order with no extra properties.

The production RaffleManager is deployed on **Base mainnet (chain ID `8453`)** at [`0xbd4452ca27e71c9bd00fac9da50460d617d5d3ff`](https://basescan.org/address/0xbd4452ca27e71c9bd00fac9da50460d617d5d3ff). Read `getRaffle(raffleId).snapshotHash` and compare it case-insensitively with your computed hash. A match proves that the published wallets, entry counts, and winner count are the inputs committed before the draw.

## Pyth Randomness

RaffleManager requests randomness from [Pyth Entropy V2](https://docs.pyth.network/entropy). Pyth fulfills the request in a later transaction, and RaffleManager records the final `randomNumber` on-chain in the `RaffleFulfilled` event and the raffle record.

You can inspect [RaffleManager events on BaseScan](https://basescan.org/address/0xbd4452ca27e71c9bd00fac9da50460d617d5d3ff#events). For example, [this fulfillment transaction](https://basescan.org/tx/0x83f2e469eabe6fb4bc93d58dcfc20417990b022745455a12ce70e4c410281b1b) recorded the random number for raffle `2`.

## Reproducing the Winners

For each draw index `i`, starting at `0`, calculate:

```text
drawHash[i] = keccak256(
  abi.encodePacked(randomNumber, uint256(i))
)

target[i] = uint256(drawHash[i]) mod remainingEntries
```

Walk the wallets in ascending `canonicalIndex`, adding their entry counts until the target falls inside a wallet's range. Record that wallet, remove it and all of its entries, and then calculate the next draw against the new `remainingEntries` total. This removal is what prevents one wallet from winning twice.

Draw `0` is prize rank `1`, draw `1` is prize rank `2`, and so on.

### TypeScript Verifier

Save this as `verify-raffle.ts`, install `viem`, and run it with a snapshot URL, the RaffleManager address, and a Base RPC endpoint:

```bash
npx tsx verify-raffle.ts \
  https://api-tbi.boost.xyz/raffles/2/snapshot \
  0xbd4452ca27e71c9bd00fac9da50460d617d5d3ff \
  https://mainnet.base.org
```

```ts
import {
  createPublicClient,
  encodePacked,
  http,
  keccak256,
  toBytes,
  type Address,
  type Hex,
} from "viem";
import { base } from "viem/chains";

type SnapshotRow = {
  canonicalIndex: number;
  walletAddress: Address;
  ticketCount: string;
};

type Snapshot = {
  version: 2;
  raffleId: number;
  numberOfWinners: number;
  rows: SnapshotRow[];
  totalTickets: string;
};

const [snapshotUrl, managerAddress, rpcUrl] = process.argv.slice(2);
if (!snapshotUrl || !managerAddress || !rpcUrl) {
  throw new Error("Usage: tsx verify-raffle.ts <snapshot-url> <manager-address> <rpc-url>");
}

const response = await fetch(snapshotUrl);
if (!response.ok) throw new Error(`Snapshot request failed: ${response.status}`);
const input = (await response.json()) as Snapshot;

const rows = input.rows.map((row, index) => {
  const walletAddress = row.walletAddress.toLowerCase() as Address;
  if (row.canonicalIndex !== index) throw new Error("Invalid canonicalIndex order");
  if (row.walletAddress !== walletAddress) throw new Error("Wallet is not lowercase");
  if (index > 0 && input.rows[index - 1]!.walletAddress >= walletAddress) {
    throw new Error("Wallets are not in lexicographic order");
  }
  if (BigInt(row.ticketCount) <= 0n) throw new Error("Invalid ticketCount");
  return { canonicalIndex: index, walletAddress, ticketCount: row.ticketCount };
});

const totalTickets = rows.reduce((sum, row) => sum + BigInt(row.ticketCount), 0n);
if (totalTickets !== BigInt(input.totalTickets)) throw new Error("totalTickets mismatch");
if (input.numberOfWinners < 1 || input.numberOfWinners > rows.length) {
  throw new Error("Invalid numberOfWinners");
}

const snapshot: Snapshot = {
  version: input.version,
  raffleId: input.raffleId,
  numberOfWinners: input.numberOfWinners,
  rows,
  totalTickets: input.totalTickets,
};
const computedHash = keccak256(toBytes(JSON.stringify(snapshot)));

const client = createPublicClient({ chain: base, transport: http(rpcUrl) });
const raffle = await client.readContract({
  address: managerAddress as Address,
  abi: [{
    type: "function",
    name: "getRaffle",
    stateMutability: "view",
    inputs: [{ name: "raffleId", type: "uint256" }],
    outputs: [{
      name: "",
      type: "tuple",
      components: [
        { name: "snapshotHash", type: "bytes32" },
        { name: "randomNumber", type: "bytes32" },
        { name: "sequenceNumber", type: "uint64" },
        { name: "requestedAt", type: "uint64" },
        { name: "status", type: "uint8" },
      ],
    }],
  }] as const,
  functionName: "getRaffle",
  args: [BigInt(snapshot.raffleId)],
});

if (computedHash.toLowerCase() !== raffle.snapshotHash.toLowerCase()) {
  throw new Error(`Snapshot hash mismatch: ${computedHash} != ${raffle.snapshotHash}`);
}
if (raffle.randomNumber === `0x${"00".repeat(32)}`) {
  throw new Error("Randomness has not been fulfilled");
}

let pool = rows.map((row) => ({ ...row, entries: BigInt(row.ticketCount) }));
const winners: Array<{ prizeRank: number; walletAddress: Address }> = [];

for (let i = 0; i < snapshot.numberOfWinners; i += 1) {
  const remainingEntries = pool.reduce((sum, row) => sum + row.entries, 0n);
  const drawHash = keccak256(
    encodePacked(["bytes32", "uint256"], [raffle.randomNumber as Hex, BigInt(i)]),
  );
  const target = BigInt(drawHash) % remainingEntries;
  let cumulative = 0n;
  const winnerIndex = pool.findIndex((row) => {
    cumulative += row.entries;
    return target < cumulative;
  });
  if (winnerIndex === -1) throw new Error("No winner found");
  const [winner] = pool.splice(winnerIndex, 1);
  winners.push({ prizeRank: i + 1, walletAddress: winner!.walletAddress });
}

console.log({ raffleId: snapshot.raffleId, snapshotHash: computedHash, winners });
```

<Note>
  The verifier needs only the public snapshot, the RaffleManager address, and an RPC endpoint. Use a trusted Base RPC provider for independent verification.
</Note>

## Claiming Prizes

Winners appear after Pyth fulfills the randomness request and Rabbithole completes the deterministic draw. A prize becomes claimable after the reward campaign and its claim data are published. If you won, the raffle panel shows your prize and a **Claim** button when it is ready.

The snapshot commits the wallets, entry counts, and number of winners. It does **not** commit prize amounts. Prize ranks and amounts are published separately through the raffle's reward campaign.
